# PHYEL — Digital Fashion Art Museum

> Musée de la Mode Numérique | 数字服装艺术博物馆

PHYEL 是一个基于瑞士国际主义排版风格的数字服装艺术博物馆开源项目。

## 🤝 如何参与贡献 (Contributing)

我们非常欢迎来自全球的开发者、设计师和艺术爱好者参与构建！

### 贡献方向
- 🎨 **设计与 UI**：优化 CSS 瑞士排版网格，提升跨端适配。
- 🌐 **多语言与翻译**：校对或新增更多语言（如德语、日语、西班牙语等）。
- 🖼️ **艺术档案与数据**：补充更多名画与高定秀场的色彩萃取数据。
- 💻 **3D 与交互**：增强 Three.js / Canvas 的服装 3D 渲染与交互效果。

### 提交代码流程
1. **Fork** 本仓库到你的个人账号。
2. 创建你的特性分支 (`git checkout -b feature/AmazingFeature`)。
3. 提交你的修改 (`git commit -m 'Add some AmazingFeature'`)。
4. 推送到你的分支 (`git push origin feature/AmazingFeature`)。
5. 在本仓库提交一个 **Pull Request (PR)**。
